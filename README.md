**End-Rage App** — это кастомный, легковесный и функциональный Minecraft-лаунчер для игрового сообщества **End-Rage Team**. Проект является модифицированной версией (форком) оригинального лаунчера с открытым исходным кодом **Modrinth App**.

Основная цель проекта — предоставить игрокам стабильный клиент с интеграцией сервисов Ely.by (для работы скинов на неофициальных аккаунтах), автоматическим получением новостей из Telegram-канала проекта и встроенным каталогом модов.

---

## ✨ Основные особенности

* **Поддержка неофициальных аккаунтов (Пиратка):** Возможность играть бесплатно с оффлайн-профилем без обязательной авторизации через Microsoft.
* **Автоматические скины Ely.by:** Встроенная поддержка `authlib-injector`. Загрузите скин на Ely.by, войдите под тем же ником в лаунчере, и скин автоматически появится в игре.
* **Telegram-новости:** Лента новостей нашего Telegram-канала выводится прямо в сайдбар лаунчера и автоматически обновляется раз в минуту.
* **Каталог Modrinth:** Поиск, скачивание и обновление тысяч модов, сборок, ресурспаков и шейдеров в один клик.
* **Высокое быстродействие:** Ядро написано на Rust (Tauri), интерфейс — на Vue 3. Лаунчер запускается мгновенно и не расходует лишнюю оперативную память.

## 🛠️ Разработка и сборка

Проект использует `pnpm` в качестве пакетного менеджера.

### Установка зависимостей:
```bash
corepack enable
pnpm install
```

### Запуск в режиме разработки:
```bash
pnpm --filter @erteam/app dev
```

### Сборка лаунчера:
Сборка дистрибутивов настроена автоматически через **GitHub Actions** в файле `.github/workflows/build-and-release.yml`. При создании и пуше любого тега версии (например, `v1.0.0`) GitHub сам скомпилирует лаунчер под Windows, macOS и Linux и создаст релиз во вкладке **Releases**.
